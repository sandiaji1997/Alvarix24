FAQ

Questions from first API users.

Is Alvarix SecureAI available as an API?

Yes. Current products are API-first: Risk API, Payment Intelligence, and Decision Engine.

Does the API support authentication?

Yes. Account actions use JWT bearer authentication, while risk and decisioning calls use the `x-api-key` header.

Is Indonesian supported?

Yes. The website supports English and Indonesian content for public presentation.

Are Command Center and Agent Engine available?

No. They are roadmap products only and are not presented as current products.
