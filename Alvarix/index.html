API Example

Score a transaction with one API call.

Send context from your backend and receive an explainable risk score, decision, and threat tags.

RequestPOST /api/risk-score
{
  "user_id": "usr_123",
  "context": "transaction",
  "amount": 125.50,
  "location": "ID",
  "device": "android",
  "metadata": {
    "payment_method": "card",
    "merchant_id": "mrc_456"
  }
}
ResponseRisk decision
{
  "riskScore": 27,
  "decision": "APPROVE",
  "threatTags": [
    "trusted_device",
    "normal_velocity"
  ]
}

FAQ

Questions from first API users.

Is Alvarix SecureAI available as an API?

Yes. Current products are API-first: Risk API, Payment Intelligence, and Decision Engine.

What is Alvarix?

Alvarix SecureAI is a Global AI Risk & Threat Intelligence Platform for API-first risk scoring, fraud detection, behavior analytics, payment intelligence, and decision support.

How does Risk Scoring work?

Your backend sends transaction, login, account, device, or payment context. Alvarix returns a risk score, decision, confidence, reasons, and threat tags.

How do I integrate the API?

Create an account, obtain an API key, then call the Risk API from a trusted server-side environment using the `x-api-key` header.

Do I need a credit card?

No credit card is required for initial API access requests or Free plan evaluation.

Is there a free plan?

Yes. The Free plan includes 1,000 requests per month for evaluation and early testing.

What payment methods are supported?

Payment checkout is prepared for Paddle onboarding. Supported payment methods will depend on the final Paddle checkout configuration.
